# App 与实验配置文档索引

本目录集中维护 app 相关说明和实验配置说明

## 文档导航

1. `app部署与运行.md`
   - app 目录结构
   - 可执行程序说明
   - 配置文件分层
   - 编译与基础运行

2. `实验配置与脚本.md`
   - 单机实验脚本说明
   - 正确性/平衡/极限/稳定性测试建议
   - 关键日志指标与判读

3. `三机严格版.md`
   - A/B/C 三机分工
   - 占位符模板说明
   - 三种场景一键启动步骤

4. `四机严格版.md`
   - A/B1/B2/C 四机分工
   - 四机场景模板与一键脚本
   - 端口与占位符规划

5. `四机推荐配置.md`
   - 每台机器推荐硬件配置
   - 网卡/网线/交换机要求
   - DPDK 场景网络建议

6. `DPDK采集配置与使用.md`
   - DPDK 安装后检查项（工具链/网卡/大页）
   - 本项目 DPDK 采集接入要点
   - 联调步骤与常见排障
   - 是否需要一键脚本的建议

## 推荐阅读顺序

1. 先读 `app部署与运行.md`
2. 再读 `实验配置与脚本.md`
3. 需要分布式严格测试时读 `三机严格版.md`
4. 四机扩展场景读 `四机严格版.md`
5. 实验计划硬件选型读 `四机推荐配置.md`
6. 准备启用 DPDK 采集时读 `DPDK采集配置与使用.md`
