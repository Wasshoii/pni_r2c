# 四机分布式推荐配置（含网卡/网线/交换机）

本文档是多机硬件选型参考（Coin + worker；采集阶段另见 `DPDK采集配置与使用.md`），目标是覆盖当前 2.5 GB/s 实际需求并为 6 GB/s 潜在峰值预留余量。

## 1. 主机配置建议

### 1.1 A 机（主控+符合）

1. CPU：32 核及以上（推荐 AMD EPYC 93xx 或 Intel Xeon 64xx）
2. 内存：256 GB DDR4/DDR5
3. GPU：2 x A4000 起步，推荐 2 x A6000 或更高
4. 网卡：
   - 1 x 25GbE（最低）
   - 推荐 2 x 25GbE（数据面+冗余/扩展）
5. 存储：2 TB NVMe

### 1.2 B1/B2 机（采集+单事件转换，DPDK 关键）

1. CPU：48 核及以上，主频优先
2. 内存：128 GB（推荐 256 GB）
3. GPU：按 R2S 路径选择，CPU-only 可不配
4. 网卡：
   - 至少 2 x 25GbE（入口/出口分离更好）
   - DPDK 推荐 Intel E810 或 Mellanox ConnectX-6
5. 存储：1~2 TB NVMe

### 1.3 可选：回放/数据源机

当前 RDMA 实验不需要独立发包机（worker 用 `synthetic` / `lsingle_replay`）。若以后做 raw 回放或采集压测，可另备一台：

1. CPU：32 核及以上
2. 内存：128 GB
3. 网卡：2 x 25GbE（或 1 x 100GbE）
4. 存储：2 TB NVMe（真实回放数据缓存）

## 2. 网络与交换机建议

### 2.1 交换机

1. 最低建议：25GbE 非阻塞交换机，>= 8 个 25G 端口
2. 推荐：支持 100GbE 上行，背板 >= 1.2 Tbps
3. 建议能力：
   - 大缓存
   - 支持链路聚合（LACP）
   - 支持 PFC/ECN（可选）

### 2.2 网卡与驱动要求（DPDK）

1. 驱动兼容：确认支持 vfio-pci / igb_uio
2. 队列数：网卡多队列能力与 CPU 核数匹配
3. NUMA：网卡插槽与绑定核/内存同 NUMA 节点

### 2.3 网线与模块

1. 25GbE：
   - 同机柜短距离：SFP28 DAC（1~3m）
   - 跨机柜：SFP28 光模块 + OM4 双芯光纤
2. 100GbE：
   - QSFP28 DAC（短距）或 QSFP28 光模块 + OM4
3. 控制面网络可使用独立 1/10GbE

## 3. 控制面端口（当前 RDMA 实验）

1. Coin gRPC：默认 `50061`（见 `app/config/rdma_cluster/`）
2. 采集控制面（本阶段 coin 不启用 AcquisitionMaster）：预留 `50093`

## 4. 极限测试建议

1. 先用 `synthetic` / `lsingle_replay` 跑通握手与符合，再上采集
2. 关键观测见 `状态机与调试.md`：
   - `pend` / `rdma` / `buf` / `lag`
   - `recvRate` vs `procRate`、`memUsagePct`

## 5. 建议的预算档位

1. 标准档（25GbE）：适合覆盖 2.5 GB/s + 冗余
2. 进阶档（双 25GbE/节点）：适合持续高压与稳定性试验
3. 高配档（100GbE 骨干）：适合未来 6 GB/s 潜在峰值验证
