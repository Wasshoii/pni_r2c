# 测试说明

测试分两层，不要混用通过标准。

1. **进程测试**：本机 `bin/test/*`。分类、每条用途/用法/与 app 的关系见 [测试/README.md](../测试/README.md)。
2. **多机实验**：`app/experiments/rdma_cluster/` + `app/config/rdma_cluster/`。用法与判据见 [RDMA多机实验.md](RDMA多机实验.md)。

```bash
cd pni_r2c
./build.sh --tests
ctest --test-dir build/tests/core -L core --output-on-failure
ctest --test-dir build/tests/pni  -L pni  -LE "integration|manual" --output-on-failure
```

Preset 总表见 [BUILD_AND_SETUP.md](../BUILD_AND_SETUP.md)。
