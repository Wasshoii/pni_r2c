# 单元模块测试

无完整 worker/coin 进程编排，或只测单一计算/数据面模块。每条先一句用途，再四项：模块、用法、依赖、与 app。

源码在 `tests/correctness/`。编译总入口见 [README.md](README.md)。下列「用法」均在 `pni_r2c/` 下、二进制在 `bin/test/`。

## test_coin_synthetic_singles

测试 worker synthetic 源的配对公式、分块拼接与时间单调。

- **模块**：`core/streaming/SyntheticSingles`（CPU，无 gRPC）。
- **用法**：preset `linux-release-tests-pni`。`./bin/test/test_coin_synthetic_singles` 或 `ctest --test-dir build/tests/pni -R test_coin_synthetic_singles`。标签 `pni`，默认 CI 跑。
- **依赖**：无 GPU、无数据文件。
- **app**：`app_acq_r2s_node` 的 `source.type=synthetic`。worker 按 `pushChunkSingles` 调 `fillSyntheticChunk`；本测试断言配对公式、chunk 拼接、stream wrap。墙钟节流 / jitter / 本地 pause **不**在这里测。

## test_rdma_dataplane_loopback

测试本机 RDMA 槽环写入、credit 与 SOF/EOF 标志是否正确。

- **模块**：`RdmaWriteSender` / `RdmaRecvServer` / 槽协议与 credit，不经 CoincidenceClient。
- **用法**：随 pni 的 `LOCAL_GRPC_COIN` 编译。`./bin/test/test_rdma_dataplane_loopback`。标签 `pni`，默认 CI 跑。
- **依赖**：InProcess 必跑；同进程 RNIC 无 verbs 则 skip，不算失败。
- **app**：worker 发送槽、coin 接收环。覆盖 golden、credit wrap、反压、SOF/EOF、`acquireTxSlot`+`commitTxSlot`。不测握手与 PAUSE。

## test_r2s_50100_multi_gpu

测试 50100 单事件转换在多 GPU 上的正确性（与单 GPU 结果一致）。

- **模块**：`R2S50100MultiGpuEngine` vs 单 GPU 遗留路径，同一 raw 段 singles 是否一致。
- **用法**：preset `linux-release-tests-cuda`。`./bin/test/test_r2s_50100_multi_gpu [--data_path PATH] [--cali_path PATH] [--max_segments N]`。标签 `cuda integration`。
- **依赖**：CUDA、9120 raw + 校正（默认 `/media/lenovo/1TB/50100data/test_9120` 与 `pni_res/caliFile`）。
- **app**：`app_acq_r2s_node` 的 BDM50100 多 GPU R2S。不含 RDMA。

## test_coin_multi_gpu

测试符合计算在多 GPU 上与单 GPU 结果一致。

- **模块**：`CoincidenceMultiGpuEngine` vs libpni 单 GPU `getDListmode`。
- **用法**：`./bin/test/test_coin_multi_gpu [--data_path PATH] [--max_singles N]`。标签 `cuda integration`。
- **依赖**：CUDA、9120 `.lsingle`。
- **app**：`app_coin_master` 符合引擎。不含 RDMA / TimeAligner 跨节点水印。

## test_coin_carry_boundary

测试流式分段符合在窗口边界用 carry 能否找回丢失的符合。

- **模块**：流式分段符合的尾部 carry（整段金标准 / 无 carry / 有 carry）。
- **用法**：`./bin/test/test_coin_carry_boundary [--singles-dir=PATH] [--max-singles=N] [--segment-duration-ps=N]`。标签 `cuda integration`。无 `.lsingle` 时非 0 退出。
- **依赖**：CUDA、singles 目录。
- **app**：`app_coin_master` 滑动窗口边界。不经 gRPC。

## test_coin_time_shard

测试时间分片 epoch 交接：双 `StreamingTimeAligner` 对照 9120 金标准。

- **模块**：`completeEpoch` / `takeHandoff` / `applyHandoff`；LMF 带 `epochId` 与符合 PET 时间，按时间归并。
- **用法**：preset `linux-release-tests-pni`（需 `R2C_BUILD_TEST_STREAMING`）。`./bin/test/test_coin_time_shard`。标签 `cuda integration`。
- **依赖**：CUDA、9120 `.lsingle`（默认 `/media/lenovo/1TB/50100data/test_9120`）。无数据则 skip（退出 0）。
- **app**：符合时间分片的 aligner 层；不经 RDMA。控制面/Ship 见 `test_rdma_orchestration`。

## test_app_config_parse

测试 AppConfig 能否解析 example 与 InProcess 冒烟 JSON；有 `bin/app/*` 时再跑 `--dry-run`。

- **模块**：`app/common/AppConfig`（解析 example 与 `app/config/tests/inprocess_smoke/`）。不拉起数据面。
- **用法**：preset `linux-release-tests-pni`。`./bin/test/test_app_config_parse` 或 `ctest --test-dir build/tests/pni -R test_app_config_parse`。标签 `pni`，默认 CI 跑解析。`--dry-run` 仅在 `bin/app/app_coin_master` / `app_acq_r2s_node` 已编出时执行，缺失 skip。
- **依赖**：无 GPU、无数据文件。dry-run 需要 app 二进制（`./build.sh --apps`）。
- **app**：覆盖 JSON 字段是否进 `AcqR2SNodeConfig` / `CoinMasterConfig`。不测握手与发送。

## test_timesync_algorithm

测试多节点时钟漂移校正算法（不走真实 gRPC）。

- **模块**：`grpcService/timesync` 算法（模拟漂移时钟，无真实 gRPC server）。
- **用法**：preset `linux-release-tests-core`。`./bin/test/test_timesync_algorithm`。标签 `core`，默认 CI 跑。
- **依赖**：仅 gRPC/protobuf 工具链。
- **app**：**未接线**。`app_acq_r2s_node` / `app_coin_master` 不创建 TimeSync 客户端。

## test_pni_r2s_offline（手工）

用盘上 raw 离线跑 50100 R2S，产出 singles 供对照（非 CI 断言）。

- **模块**：离线 `R2SStreamProcessor` 跑盘上 raw（实验室脚本，不是 CI 断言）。
- **用法**：`./bin/test/test_pni_r2s_offline [--data_path PATH] [--cali_path PATH] [--out_path PATH]`。默认路径写死本机 9120。标签 `cuda manual`。
- **依赖**：CUDA、本机 raw/校正。`main` 里大量旧用例已注释，当前默认跑 50100 单环 callback。
- **app**：与 worker 同用 R2S 实现，但无 RDMA、无 JSON 配置。不要当回归套件。

## test_pni_coin_offline（手工）

用盘上 singles 离线做符合，检查 prompt/delay 通道分布（非 CI 断言）。

- **模块**：离线 `MergeAndCoin` 读 singles 写 prompt/delay LMF，并打通道间隔统计。
- **用法**：`./bin/test/test_pni_coin_offline`（路径在源码常量里，NECR 盘）。标签 `cuda manual`。
- **依赖**：CUDA、硬编码 singles 目录存在。
- **app**：离线符合对照；在线路径是 `StreamingTimeAligner` + 多 GPU 引擎，不是本文件的 merge 主路径。
