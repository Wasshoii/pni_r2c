# 通信测试

测握手、数据面协议或控制面 RPC，不要求完整 Acq→R2S→符合产物。每条先一句用途。源码在 `tests/correctness/`。编译总入口见 [README.md](README.md)。

## test_rdma_orchestration

测试 worker↔coin 的 Register / OpenDataPlane / Start 握手、PAUSE、InProcess 发送、通道 remap，以及时间分片双 destination / 租约 / Ship。

- **模块**：`CoincidenceClient` + `CoinGrpcNode`：Register → OpenDataPlane → Start、Heartbeat/PAUSE、InProcess 分块发送、`requireRoce` 无设备拒绝、`remapLocalToGlobalChannels` 后 ingest 的 `channelIndex`。时间分片：`CMD_SET_ACTIVE_COIN` 冷切、同进程 `EpochHandoff` 热切、`TimeLease` FSM、`shipEpochHandoffViaDataplane`。
- **用法**：preset `linux-release-tests-pni`。`./bin/test/test_rdma_orchestration` 或 `ctest --test-dir build/tests/pni -R test_rdma_orchestration`。标签 `pni integration`。
- **依赖**：libpni；符合引擎会初始化 GPU（本机有 CUDA）。同进程 RoCE 无 verbs 则 skip。不要求 9120 文件。
- **app**：最接近双进程握手。worker 的 `CoincidenceClient`、coin 的 `CoinGrpcNode`。双节点 synthetic 至少要求 `prompt>0 && delay>0`（不强制等于 truth）。精确配对仍以 `test_coin_synthetic_singles` 为准。跨机带宽 **不** 进本测试。

## test_rdma_singles_ingress

测试 `.lsingle` 经数据面灌入 coin 接收环的连续性与吞吐（不算符合）。

- **模块**：L2：`.lsingle` 经 `sendSinglesView` + 数据面灌到只收不计算的 host（Register / WaitForStart / OpenDataPlane、chunk 连续）。无符合 CUDA。
- **用法**：preset `linux-release-tests-cuda`。  
  `./bin/test/test_rdma_singles_ingress --data-root /media/lenovo/1TB/50100data/test_9120`  
  `--send-only` 为 CreditOnly 黑洞。标签 `cuda integration`。
- **依赖**：9120 双节点 `.lsingle`。吞吐数字是 InProcess memcpy 上限，不是 RoCE 线速。
- **app**：coin 收包路径（ingest 前）。对应 `app_coin_master` 的 RDMA recv，不算 TimeAligner。

## test_acq_control_init

测试采集 Master 向节点下发任务并进入 CONFIGURED。

- **模块**：`AcquisitionMaster` + 两个 `acquisitionNode`：连上并 `DistributeTasks` 到 `CONFIGURED`。
- **用法**：`./bin/test/test_acq_control_init`。标签 `pni`，默认 CI 跑。
- **依赖**：无采集硬件、无 DPDK。
- **app**：**现行 `app_coin_master` 忽略 `acquisitionControl`**。给未来采集控制预留，与 RDMA 热路径无关。

## test_timesync_grpc

测试 timesync 的 gRPC 同步、多轮校正与并发客户端。

- **模块**：`TimeSyncService` gRPC（多轮 sync、并发客户端、模拟延迟）。
- **用法**：preset `linux-release-tests-core`。`./bin/test/test_timesync_grpc`。标签 `core`。
- **依赖**：本机 loopback 端口。
- **app**：同 [单元模块 timesync](单元模块.md#test_timesync_algorithm)，**未接线**。

## test_rdma_recv_stub（手工对端）

提供不跑符合的 RDMA 接收端，供手工对端联调。

- **模块**：自写 `LocalCoincidenceReceiverService`（标题即 No Coin）：OpenDataPlane + ingest 计数，**不**跑 `CoinGrpcNode` / 符合。
- **用法**：`./bin/test/test_rdma_recv_stub [--address 127.0.0.1:50061] [--expected-node-count 2]`，再另开 worker 或 `test_r2s_rdma_send --no-local-receiver`。标签 `pni integration manual`。
- **依赖**：对端发送进程。`test_r2s_rdma_send` 已内嵌同类接收器，编排测试已用真实 coin。
- **app**：早期联调替身，不是 `app_coin_master`。默认 ctest 不跑。
