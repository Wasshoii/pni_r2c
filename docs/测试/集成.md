# 集成测试

多模块串起来，接近本机上的 worker + coin。每条先一句用途。跨机实验仍走 [RDMA多机实验.md](../app以及实验配置/RDMA多机实验.md)。编译总入口见 [README.md](README.md)。

默认 9120 根目录：`/media/lenovo/1TB/50100data/test_9120`。校正：`/media/lenovo/1TB/50100data/pni_res/caliFile`。

## test_app_inprocess_smoke

测试真实 `app_coin_master` + 两路 `app_acq_r2s_node` 的 InProcess synthetic 握手与 `sent≈received`。

- **模块**：进程级拉起 `bin/app/app_coin_master` 与 `bin/app/app_acq_r2s_node`，配置 `app/config/tests/inprocess_smoke/`（`requireRoce=false`、`forceInProcess=true`、很小的 pairs）。
- **用法**：preset `linux-release-tests-pni`。`./bin/test/test_app_inprocess_smoke` 或 `ctest --test-dir build/tests/pni -R test_app_inprocess_smoke`。标签 `pni integration`。
- **依赖**：符合引擎会碰 GPU。二进制不存在（只编了 tests、没编 apps）则 **skip**，不算失败。先 `./build.sh --apps` 再跑才会真正冒烟。现行 InProcess 数据面是进程内 session map，**不能跨进程**；无 RNIC 时本测试 skip。有 verbs 时会改用本机 RoCE 再跑一遍。
- **app**：覆盖 app main + JSON，不是库层编排替身。成功路径断言握手（`startIssued` / `dataplaneOpen=2`）、进程退出 0、`sent≈received`。同进程 InProcess 握手见 `test_rdma_orchestration`。

## test_local_grpc_r2s

测试两路 R2S 节点经 RDMA 发到本机接收端（不含符合计算）。

- **模块**：两路 `r2sNode` 读 raw → R2S → RDMA 发到本进程假接收端（不算符合）。
- **用法**：preset `linux-release-tests-cuda`。  
  `./bin/test/test_local_grpc_r2s --data-root <9120> [--calibration-dir PATH] [--parallel-nodes]`  
  `--no-local-receiver` 时需另开 `test_local_grpc_coin`。标签 `cuda integration`。
- **依赖**：CUDA、双节点 raw、校正。ctest 120s，全量 9120 请直接跑二进制。
- **app**：`app_acq_r2s_node` 的 R2S+发送；接收侧不是 `app_coin_master`。

## test_local_grpc_coin_stream

测试预计算 singles 灌入真实 coin 后能否产出 prompt/delay。

- **模块**：L3：`grpc_singles_replay` 把预计算 `.lsingle` 灌进真实 `CoinGrpcNode`（TimeAligner + 符合），检查 prompt/delay LMF。
- **用法**：`./bin/test/test_local_grpc_coin_stream --data-root <9120> [--disable-multi-gpu]`。标签 `cuda integration`，CTest 超时 7200s。
- **依赖**：双节点 `.lsingle`、CUDA（可关多 GPU）。**无 R2S**。
- **app**：`app_coin_master` 收数+符合；数据形态接近 worker `lsingle_replay`。

## test_local_grpc_r2s_coin

测试本机双 R2S + coin 全链路（R2S → RDMA → 符合）。

- **模块**：单进程：`CoinGrpcNode` + 两路 R2S 节点，R2S → RDMA → aligner。最接近双 worker + master。
- **用法**：`./bin/test/test_local_grpc_r2s_coin --data-root <9120>`。标签 `cuda integration`，超时 7200s。
- **依赖**：CUDA、raw、校正。R2S 与 streaming 头冲突拆在 `test_local_grpc_r2s_coin_r2s_runner.cpp`。
- **app**：本机替身 `app_acq_r2s_node` ×2 + `app_coin_master`。不替代跨机 RoCE soak。

## test_streaming_coincidence（手工 soak）

测试流式时间对齐与符合（不经 RDMA，直接灌 singles）。

- **模块**：`StreamingTimeAligner` 直接 `push` singles，**不经 RDMA/gRPC**。默认 `test7Only`：9120 双节点流式灌入。
- **用法**：preset `linux-release-tests-pni`。`./bin/test/test_streaming_coincidence`；`--test7-only=false` 才跑 ring buffer 等小测。标签 `pni integration manual`。
- **依赖**：9120 singles、符合 GPU。ctest 默认 120s，缺数据或 soak 会挂，故默认不跑。
- **app**：只测 coin 对齐/符合内核；生产数据面见 [通信](通信.md) / 上列 L3。

## test_bdm50100_online_pipeline（手工，无断言）

模拟采集环走完 R2S 与符合并落盘，不做正确性断言。

- **模块**：模拟采集环 → R2S → `CoincidenceClient` → `CoinGrpcNode`，写出 singles 与 LMF。
- **用法**：`./bin/test/test_bdm50100_online_pipeline --help`。标签 `cuda integration manual`，超时 7200s。
- **依赖**：CUDA、本机 raw 配置（见 `--help`）。**没有**基线比对，只产文件供外部对比。
- **app**：在线链路的单机演练，不是回归。正确性用 `test_local_grpc_r2s_coin` 或离线 GPU 一致测。
